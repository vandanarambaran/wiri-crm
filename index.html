One-time setup — connect Google in 3 steps

This CRM reads contacts live from your Google Sheet and syncs status from Gmail. You only do this once.

  1. Go to console.cloud.google.com → your project → ensure Gmail API and Google Sheets API are both enabled
  2. Under Credentials → OAuth 2.0 Client ID, confirm https://vandanarambaran.github.io is in Authorized JavaScript origins
  3. Paste your Client ID below and click Save & Connect
