One-time setup — connect Gmail in 3 steps

This CRM reads your Gmail directly to detect sent emails and replies. You only do this once.

  1. Go to console.cloud.google.com → create a project → enable the Gmail API
  2. Go to APIs & Services → Credentials → Create OAuth 2.0 Client ID. Choose Web application. Add http://localhost and the URL of this file to Authorized JavaScript origins.
  3. Copy your Client ID and paste it below, then click Save and Connect Gmail.
